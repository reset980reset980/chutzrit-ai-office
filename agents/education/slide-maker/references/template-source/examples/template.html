Chapter 2 · 모드 비교

Interactive vs Non-interactive

실시간 협업 모드와 자동화 배치 모드의 차이점

I
Interactive 모드
터미널에서 Codex와 실시간으로 대화하며 코드를 수정합니다. 각 변경 사항을 확인하고 승인할 수 있습니다.
  • 변경 전 미리보기 제공
  • 단계별 승인 가능
  • 탐색적 작업에 최적
  • codex "기능 설명" 형식 사용
N
Non-interactive 모드
사람의 개입 없이 완전 자동으로 실행됩니다. CI/CD 파이프라인과 스크립트 통합에 사용합니다.
  • --full-auto 플래그로 활성화
  • GitHub Actions 통합 가능
  • 반복 작업 배치 처리
  • 승인 과정 없음 — 신중하게 사용

Chapter 4 · 실전 활용

Codex 3대 활용 영역

코드 생성 · 리뷰 · 테스트 — 개발 사이클 전체를 자동화

1
코드 생성
기능 설명만으로 완성된 코드 파일을 생성합니다. 컴포넌트, API 엔드포인트, 유틸 함수 모두 가능합니다.
  • 자연어 → 완성 코드
  • 기존 코드 스타일 학습
  • 다국어 파일 동시 생성
2
코드 리뷰
PR 변경 사항을 분석해 버그, 성능 이슈, 보안 취약점을 자동으로 찾아냅니다.
  • 취약점 자동 감지
  • 개선 제안 인라인 코멘트
  • GitHub PR 연동 가능
3
테스트 자동화
소스 코드를 읽고 엣지 케이스를 포함한 유닛·통합 테스트를 자동으로 작성합니다.
  • Jest / Pytest 지원
  • 엣지 케이스 자동 추론
  • 커버리지 목표 설정 가능

Chapter 4 · Python API

Codex API 직접 호출

openai 라이브러리로 Codex 에이전트를 프로그래매틱하게 제어

# Codex 에이전트 API 호출 예제
import openai
import os

client = openai.OpenAI(
    api_key=os.environ["OPENAI_API_KEY"]
)

def run_codex_task(task_description: str, repo_path: str) -> dict:
    """Codex 에이전트에게 작업을 위임하고 결과를 반환합니다."""

    response = client.responses.create(
        model="codex-mini-latest",
        input=task_description,
        tools=[{"type": "computer_use_preview"}],
        environment={"type": "local", "path": repo_path},
    )

    return {
        "id": response.id,
        "status": response.status,
        "changes": [
            item for item in response.output
            if item.type == "file_edit"
        ],
        "summary": response.output_text,
    }

# 사용 예시
result = run_codex_task(
    task_description="테스트 커버리지 80% 달성을 위한 유닛 테스트 작성",
    repo_path="/home/user/my-project",
)
print(f"변경된 파일: {len(result['changes'])}개")

Chapter 5 · CI/CD 자동화

GitHub Actions 통합

PR 생성 시 Codex가 자동으로 코드 리뷰 & 테스트 커버리지 검사

이 워크플로우 하나로
모든 PR에 자동 리뷰가
달립니다.

  • on: pull_request 트리거
  • Codex가 변경 diff 분석
  • 인라인 코멘트 자동 작성
  • 테스트 미통과 시 머지 차단
  • OPENAI_API_KEY 시크릿 등록 필수
--full-auto 모드로 승인 없이 자동 수정도 가능 
# .github/workflows/codex-review.yml
name: Codex Auto Review

on:
  pull_request:
    types: [opened, synchronize]

jobs:
  codex-review:
    runs-on: ubuntu-latest
    permissions:
      contents: read
      pull-requests: write

    steps:
      - name: Checkout
        uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Setup Node
        uses: actions/setup-node@v4
        with: { node-version: '20' }

      - name: Install Codex
        run: npm install -g @openai/codex

      - name: Run Code Review
        env:
          OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
        run: |
          codex --full-auto \
            "PR 변경사항을 리뷰하고 개선점을 코멘트로 달아줘"

키워드 강조는
색상만으로

배경 형광펜, 밑줄 없이 — 폰트 컬러 하나만 바꿔도 시선이 정확히 키워드로 향합니다. 한 슬라이드에 강조색은 1가지만 사용합니다.

  • 인라인 컬러 교체 — color: var(--teal)
  • 굵기 병행 — font-weight: 600
  • 배경 형광펜 — 다크모드에서 가독성 저하
  • 밑줄 남발 — 링크와 혼동, 시선 분산

전환 & 네비게이션 · Chapter 3

Fade 전환 —
isAnimating 패턴

전환 중 중복 입력을 차단하는 이벤트 잠금 패턴은 모든 인터랙티브 UI의 기본 방어 코드입니다.

  • isAnimating = true — 전환 시작 시 잠금
  • transitionend 이벤트로 잠금 해제
  • { once: true } — 리스너 자동 정리
  • setTimeout 500ms fallback 필수
권장 전환 속도
360ms
200ms 이하 — 너무 빠름
400ms 이상 — 답답한 느낌
300~360ms가 강의 최적값
코드 시각화 · Chapter 4

SlidePresentation 클래스 구조

isAnimating 잠금 + transitionend 감지 — 핵심 로직 구현

// 슬라이드 전환 엔진
class SlidePresentation {
  constructor() {
    this.slides =
      document.querySelectorAll('.slide');
    this.current = 0;
    this.isAnimating = false;
  }

  goToSlide(index) {
    if (this.isAnimating) return; // 잠금
    this.isAnimating = true;

    this.slides[this.current]
      .classList.remove('active');
    this.slides[index]
      .classList.add('active');
    this.current = index;

    this.slides[index].addEventListener(
      'transitionend',
      () => { this.isAnimating = false; },
      { once: true }
    );
  }
}
Fade CSS
.slide {
  opacity: 0;
  transition: opacity 0.36s;
  pointer-events: none;
}
.slide.active {
  opacity: 1;
  pointer-events: auto;
}
GPU 가속 원칙
  • opacity + transform만 animate
  • width, top 등은 리플로우 발생
  • will-change: opacity 시작 전 선언
  • will-change는 완료 후 반드시 auto로 해제
핵심 요약

바닐라 슬라이드 3가지 기둥

레이아웃 · 강조 · 전환 — 이 3가지만 잡으면 완성

1
레이아웃 & 구조
비율 기반 여백, CSS Grid 3-row, clamp() 반응형, dvh 단위. 고정 px는 절대 사용하지 않습니다.
  • dot grid 배경 텍스처
  • 좌측 정렬 기본 원칙
  • 수평 여백 8~10% 비율
2
강조 표현 기법
폰트 컬러만 변경하는 인라인 강조. 한 슬라이드에 강조색 1가지. 배경·밑줄 없음.
  • Pretendard Bold 제목
  • GmarketSans Display 임팩트
  • circled number ①②③ 마커
3
전환 & 네비게이션
Fade 360ms, isAnimating 잠금, transitionend 감지, 키보드 + 터치. 코드 블록 세로 스크롤 허용.
  • opacity + pointer-events
  • 슬라이드 진입 시 전체 표시
  • overflow-y: auto (코드 블록)

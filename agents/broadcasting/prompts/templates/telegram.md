# Telegram 뉴스레터 템플릿

Telegram 뉴스레터는 독자용 뉴스레터 채팅방에 바로 보낼 수 있는 타깃 독자용 메시지입니다.

목적은 긴 설득용 장문이 아니라, 후츠릿 타깃 독자가 오늘 바로 이해하고 행동할 수 있는 핵심 메시지를 짧게 전달하는 것입니다.

## 기본 구조

```text
## 🚀 [짧은 제목]

[핵심 내용을 자연스러운 1~2문장으로 작성. "핵심 요약" 같은 고정 라벨은 쓰지 않음]

[AI 자동화/개발/실무 관점에서 왜 중요한지 자연스럽게 연결]

- ✅ [실행 항목]
- ⚠️ [실행 항목]

**🔗 참고 링크**
- [원본/참고 URL]
```

## 작성 기준

- 독자에게 직접 보내는 뉴스레터형 메시지로 쓴다.
- 존댓말을 사용한다.
- Markdown 제목을 반드시 넣는다. Telegram에서 제목처럼 시각적으로 읽혀야 한다.
- 제목에는 필요하면 이모지 1개를 붙인다.
- `핵심 요약`, `왜 중요한가`, `바로 해볼 것` 같은 고정 라벨 제목을 일부러 넣지 않는다.
- 긴 문단을 피한다.
- 500~900자 안쪽을 기본으로 한다.
- 실행 항목은 1~2개만 둔다.
- 이모지는 전체 2~5개 안쪽으로 제한한다.
- 이모지는 제목, 실행 항목, 참고 링크 섹션에만 선택적으로 쓴다.
- 문장마다 이모지를 붙이지 않는다.
- 참고 링크가 있으면 맨 아래에 반드시 넣는다.
- 참고 링크가 없으면 링크 섹션을 만들지 않고, `참고 자료는 없습니다` 같은 문구도 쓰지 않는다.
- Telegram 뉴스레터에는 `{BLOG_URL}` placeholder를 넣지 않는다.
- 내부 승인 상태, 저장 경로, 평가 점수는 독자용 Telegram 뉴스레터에 쓰지 않는다.

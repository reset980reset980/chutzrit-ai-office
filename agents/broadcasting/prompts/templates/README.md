# 콘텐츠 템플릿

이 폴더는 콘텐츠배포팀 Writer Agent가 참고할 채널별 작성 템플릿을 보관합니다.

템플릿은 후츠릿이 실제 작성한 글과 제공한 샘플에서 구조를 추출한 것입니다. 원문을 복사하기 위한 파일이 아니라, 입력 메시지의 성격에 맞는 글 구조를 선택하기 위한 기준입니다.

## 파일 목록

- `blog.md`: 블로그 템플릿. 구현형, 개념 설명형, 인사이트형으로 분기합니다.
- `linkedin.md`: LinkedIn 포스트 템플릿. 사건/트렌드에서 실무 역량을 뽑아내는 구조입니다.
- `telegram.md`: Telegram 뉴스레터 템플릿. 타깃 독자에게 보낼 짧은 Markdown 메시지 기준입니다.

## 사용 원칙

- 입력 메시지의 성격을 먼저 판단한 뒤 템플릿을 선택합니다.
- 블로그는 무조건 이론을 쓰지 않습니다. 구현, 문제 해결, 개념 설명, 인사이트 중 입력에 맞는 형태를 선택합니다.
- YouTube는 문체 복사용이 아니라 주제, 타깃, 포지셔닝 분석용으로만 사용합니다.
- LinkedIn과 Telegram는 각 채널 목적에 맞춰 톤과 구조를 다르게 적용합니다.

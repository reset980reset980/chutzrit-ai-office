# n8n 자동화

이 폴더는 후츠릿 AI 오피스에서 사용하는 n8n 워크플로우를 보관합니다.

n8n은 복잡한 콘텐츠 생성 로직보다, 정기 실행과 알림 라우팅처럼 흐름을 연결하는 자동화에 사용합니다.

## 사용하기 좋은 작업

- 정해진 시간에 작업 실행
- Telegram 알림 라우팅
- 승인 요청 전달
- 외부 서비스 간 단순 데이터 전달
- 실패 알림과 재시도 트리거

## 코드로 처리하는 것이 나은 작업

- 콘텐츠 생성 파이프라인
- 플랫폼별 글 변환 로직
- 테스트가 필요한 상태 관리
- 블로그, LinkedIn, Telegram 채널 배포 어댑터
- 복잡한 승인 상태 처리

## 워크플로우 저장 위치

n8n에서 내보낸 워크플로우는 아래 폴더에 저장합니다.

```text
automations/n8n/workflows/
```

워크플로우 파일에는 실제 API 키, 토큰, 쿠키를 포함하지 않습니다.

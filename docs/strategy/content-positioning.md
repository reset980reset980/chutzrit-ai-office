# 콘텐츠 포지셔닝

이 문서는 후츠릿 콘텐츠가 어떤 주제를 어떤 관점으로 다룰지 정의합니다.

## 브랜드 문장

```text
도전하고 성장하는 삶을 개발합니다.
```

## 핵심 포지션

```text
AI와 개발 도구를 실무자의 실행력으로 바꿔주는 강사형 크리에이터
```

후츠릿은 어려운 기술을 대중이 원하는 결과물로 바꾸고, 그 과정을 따라 할 수 있게 가르치는 포지션입니다.

## 핵심 콘텐츠 축

### AI 자동화와 에이전트 운영

대표 소재:

- n8n
- Codex
- AI Agent
- Multi-Agent Systems
- Human In The Loop
- Discord 승인 플로우
- GitHub 자동화
- 무인 오피스

핵심 관점:

```text
AI는 말 잘 듣는 도구가 아니라, 설계와 검증이 필요한 실행 시스템이다.
```

### 개발자 생산성과 도구 세팅

대표 소재:

- Raycast
- VSCode
- Mac 개발 환경
- GitHub
- ChatGPT 활용법

핵심 관점:

```text
좋은 도구는 시간을 줄이는 것이 아니라, 반복되는 판단과 행동을 줄인다.
```

### 개발 입문과 성장

대표 소재:

- JavaScript
- 튜토리얼 지옥 탈출
- 개발자 취업
- 수강생 성장 사례
- 늦은 나이의 도전

핵심 관점:

```text
개발 학습은 재능보다 구조와 반복 가능한 피드백 루프가 중요하다.
```

### AI 시대 커리어와 관점

대표 소재:

- AI 활용과 AI 의존
- 컨텍스트 엔지니어링
- 하네스 엔지니어링
- 에이전트 오케스트레이션
- 기술 변화에서 기회 찾기

핵심 관점:

```text
AI 시대의 경쟁력은 더 좋은 답을 받는 능력이 아니라, AI가 올바르게 일하는 환경을 설계하는 능력이다.
```

## 후츠릿다운 콘텐츠 조건

좋은 후츠릿 콘텐츠는 아래 조건을 만족해야 합니다.

- 어려운 기술을 쉬운 결과물로 번역한다.
- 단순 정보 전달이 아니라 실무자가 취할 행동을 제시한다.
- 최신 기술을 다루되, 유행어보다 적용 맥락을 설명한다.
- 개인 성장과 실무 자동화를 연결한다.
- 실패와 삽질을 숨기지 않고 해결 과정으로 보여준다.
- AI를 의존 대상이 아니라 설계하고 검증할 대상으로 다룬다.

## 전략 Agent가 참고자료를 쓰는 이유

전략 Agent는 매번 타깃을 새로 만드는 역할이 아닙니다.

참고자료는 고정된 지도이고, 전략 Agent는 이번 입력에 맞는 타깃과 각도를 선택하는 역할입니다.

```text
참고자료 세트
= 후츠릿이 실제로 다루는 주제, 독자층, 강점, 브랜드 포지션의 기준

전략 Agent
= 이번 메모가 어떤 타깃에게 어떤 각도로 전달되어야 하는지 결정
```

예시:

- 입력이 `n8n으로 콘텐츠 자동 배포`라면 AI 자동화 실무자와 1인 창업자를 우선 타깃으로 잡는다.
- 입력이 `AI를 활용하는 것과 의존하는 것`이라면 AI 시대 커리어 고민형을 우선 타깃으로 잡는다.
- 입력이 `VSCode 세팅`이라면 생산성 도구 관심자와 개발 입문자를 함께 타깃으로 잡는다.

# 후츠릿 타깃 독자 정의

이 문서는 후츠릿 AI 오피스 콘텐츠가 누구를 대상으로 하는지 정의합니다.

분석 기준:

- YouTube 채널 `후츠릿 - 감성을 코딩하는 개발자`
- 채널 문구: "도전하고 성장하는 삶을 개발합니다"
- 성과가 좋았던 YouTube 영상
- 기존 LinkedIn 글
- 블로그 글 방향성
- 사용자 프로필과 목표

## 핵심 타깃

후츠릿의 핵심 타깃은 단순한 개발자가 아닙니다.

```text
AI와 개발 도구로 실행력을 키우고 싶은 실무형 학습자
```

이들은 기술 자체보다 기술로 만들 수 있는 결과, 자동화, 생산성, 커리어 전환, 실무 적용에 반응합니다.

## 1차 타깃

### AI 자동화 실무자와 1인 창업자

관심사:

- n8n
- Codex
- AI Agent
- GitHub 자동화
- 서버비 절감
- 반복 업무 자동화
- 콘텐츠/업무 파이프라인 구축

핵심 니즈:

```text
혼자서도 팀처럼 일하고 싶다.
```

잘 맞는 콘텐츠:

- n8n을 무료 서버에서 운영하는 법
- AI GitHub 에이전트로 1일 1커밋 자동화
- Discord 승인 기반 콘텐츠 배포 자동화
- AI 멀티 에이전트 운영 구조
- AI 무인 오피스 구축기

### 개발 입문자와 커리어 전환자

관심사:

- JavaScript
- 개발 환경 세팅
- VSCode
- GitHub
- 취업
- 수강생 성장 사례
- 늦은 나이의 커리어 전환

핵심 니즈:

```text
나도 개발자가 될 수 있을까?
```

잘 맞는 콘텐츠:

- 코딩 1도 몰랐던 사람이 6주 만에 개발자로 성장하는 과정
- 자바스크립트 튜토리얼 지옥 탈출
- 개발자가 맥북 사면 가장 먼저 하는 일
- 인정받는 개발자가 되기 위한 공부법

### 생산성 도구 관심자

관심사:

- Raycast
- ChatGPT 활용법
- Mac 세팅
- VSCode
- 반복 업무 단축
- 개인 워크플로우

핵심 니즈:

```text
도구를 잘 써서 시간을 아끼고 싶다.
```

잘 맞는 콘텐츠:

- Raycast 생산성 세팅
- 코딩 시간 절반으로 줄이는 VSCode 사용법
- Mac 개발 환경 세팅
- ChatGPT를 다르게 쓰는 법

### AI 시대 커리어 고민형

관심사:

- AI 시대 생존 전략
- AI 활용과 AI 의존의 차이
- 연봉 성장
- 인정받는 개발자
- 도전과 실패

핵심 니즈:

```text
AI 시대에 내가 어떻게 살아남고 성장하지?
```

잘 맞는 콘텐츠:

- AI를 활용하는 사람과 의존하는 사람의 차이
- AI 시대 호구 되지 않는 법
- 프롬프트보다 컨텍스트와 하네스가 중요한 이유
- 실패해도 다시 도전하는 성장 이야기

## 우선순위

현재 콘텐츠배포팀 MVP에서는 아래 우선순위로 타깃을 선택합니다.

1. AI 자동화 실무자와 1인 창업자
2. AI 시대 커리어 고민형
3. 생산성 도구 관심자
4. 개발 입문자와 커리어 전환자

이유:

- 현재 프로젝트의 핵심 주제가 AI 무인 오피스와 콘텐츠 자동화이기 때문입니다.
- n8n, Codex, AI Agent, Discord 승인 플로우는 1번 타깃과 가장 잘 맞습니다.
- LinkedIn과 블로그에서는 2번 타깃까지 자연스럽게 확장할 수 있습니다.

## 타깃 선택 규칙

전략 단계에서는 매번 새 타깃을 발명하지 않습니다.

이 문서의 타깃 맵을 기준으로, 입력 메모가 어느 독자군에 가장 잘 맞는지 선택합니다.

예시:

- `n8n으로 글 자동 배포` -> AI 자동화 실무자와 1인 창업자
- `AI를 활용하는 것과 의존하는 것` -> AI 시대 커리어 고민형
- `Raycast 세팅` -> 생산성 도구 관심자
- `자바스크립트 함수` -> 개발 입문자와 커리어 전환자

## 아직 필요한 보완 자료

- 성과가 좋았던 YouTube 영상 5개 중 5번째 영상
- 영상별 조회수, 클릭률, 평균 시청 지속 시간
- 댓글 반응이 좋았던 영상
- 실제 수강생 또는 고객 유형
- 앞으로 더 끌어오고 싶은 타깃
- 더 이상 끌어오고 싶지 않은 타깃

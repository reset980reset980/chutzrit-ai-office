# Figma Design Rules — 슬라이드 디자인 분석

> 분석 대상: `/source` 폴더 24장 (Casual Yet Professional 템플릿)  
> 목적: 다크모드 강의 슬라이드 구현 레퍼런스

---

## 1. 레이아웃 구조

### 여백 시스템

- **수평 패딩**: `clamp` 기준 약 9vw, 최대 8% — 1280~1440px 기준 약 8~9%, 1920px에서는 약 6%로 감소
- **수직 패딩**: 슬라이드 높이의 약 12~15% 상단, 8~10% 하단 — 기준 유지
- **요소 간 gap**: 수직 패딩 기준 유지하되, 슬라이드 내 각 요소 간 gap은 이전 대비 **1.5배** 확대  
  예) 이전 1rem → 1.5rem, 이전 1.4rem → 2.1rem, 이전 2rem → 3rem
- 여백은 고정값이 아니라 비율 기반 — 작은 화면에서도 숨쉬는 공간 유지

### 분할 방식 (반복되는 레이아웃 패턴 4가지)

| 패턴                    | 비율             | 용도                         |
| ----------------------- | ---------------- | ---------------------------- |
| 전체 좌측 정렬          | 100%             | 타이틀, 대형 텍스트 슬라이드 |
| 좌/우 분할              | 50/50 또는 45/55 | 텍스트 + 이미지/인용         |
| 좌측 레이블 + 우측 목록 | 30/70            | Agenda, 목차                 |
| 3컬럼 그리드            | 1fr/1fr/1fr      | 기능/항목 3개 나열           |

### 정렬 기준

- **기본: 좌측 정렬** — 거의 모든 텍스트가 왼쪽 앵커
- 중앙 정렬은 임팩트 강조 슬라이드(단일 메시지, 인용문)에만 사용
- 세로 기준: 수직 중앙보다 **위쪽 1/3 지점**에 타이틀이 위치하는 경우가 많음

### 배경 텍스처

- 흰색 배경 슬라이드(타이틀 포함)에만 **dot grid 패턴** 적용
- dot 밀도: 약 26~28px 간격, 아주 연한 회색 (white 기준 약 6% opacity)
- 컬러 배경 슬라이드에는 텍스처 없음 — flat 단색

### 섹션 구분 슬라이드

- 전체 화면 단색 배경 (teal / orange / yellow 로테이션)
- 우측 정렬 목록, `→` 화살표로 현재 섹션 표시
- 현재 항목: **bold white**, 나머지: regular white (동일 opacity)
- **목차 항목 폰트 크기**: `clamp(1.2rem, 2.4vw, 1.8rem)` 기준  
  섹션 슬라이드는 콘텐츠 슬라이드와 명확히 구분되는 크기 사용

## 2. 타이포그래피

### 폰트 구성

- **Display / 강조 제목**: **Gmarket Sans Bold** — 강조가 필요한 Display 타이틀 또는 임팩트 포인트에 병행 사용
- **H1~H3 / 일반 제목 + Body / 본문 + Label**: **Pretendard** — 기본 폰트로 통합 적용
  - 제목: Pretendard Bold (700~800)
  - 본문: Pretendard Regular (400) / Medium (500)
  - Label: Pretendard SemiBold (600), uppercase + wide tracking
- CDN: `https://cdn.jsdelivr.net/gh/orioncactus/pretendard/dist/web/static/pretendard.css`  
  Gmarket Sans: Google Fonts `family=Noto+Sans+KR` 계열 또는 직접 CDN

### 크기 계층 (1920×1080 기준 추정값)

| 레벨    | 역할                                 | 크기        | 굵기    | 줄간격 |
| ------- | ------------------------------------ | ----------- | ------- | ------ |
| Display | 임팩트 타이틀 (Thanks!, 단일 메시지) | 96~120px    | 900     | 1.0    |
| H1      | 슬라이드 메인 타이틀                 | 60~80px     | 800     | 1.08   |
| H2      | 섹션 타이틀, 카드 헤드               | 32~40px     | 700     | 1.2    |
| H3      | 서브헤드, 컬럼 타이틀                | **28~32px** | 700     | 1.3    |
| Body    | 일반 본문                            | **22~24px** | 400     | 1.55   |
| Caption | 각주, 보조 텍스트                    | **16~18px** | 400     | 1.5    |
| Label   | 카테고리 태그                        | 11~12px     | 600~700 | —      |

### 텍스트 줄바꿈 규칙

- **고아(orphan) 방지**: 1~3글자가 단독으로 다음 줄에 남는 구조 금지
- `code` 스니펫 (`white-space: nowrap`): 코드는 중간에 꺾이면 의미 훼손 — 반드시 한 줄 유지
- `·` 구분자 앞뒤는 `&nbsp;` 처리 + 각 세그먼트를 `white-space: nowrap` 래핑
- `max-width` 제한은 목적이 있을 때만 — 짧은 코드/키워드가 포함된 행에는 미적용 권장

### 레터스페이싱

- H1 (Pretendard Bold): `-0.01em` ~ `-0.02em` (Pretendard는 세리프보다 자간 여유 있음)
- Display (Gmarket Sans Bold): `-0.02em` ~ `-0.03em` (타이트한 자간 — 임팩트 강조)
- Body: `0` (기본값)
- Label (uppercase): `+0.15em` ~ `+0.20em` (넓은 자간)

### 강조 방식 — 인라인 컬러

- 별도 배경 없이 **폰트 컬러만 변경**하여 키워드 강조
- 같은 bold serif 유지, 색상만 teal / orange / purple 등으로 스위칭
- 예: `"Maybe you have <teal>two things</teal> to say"`
- 밑줄, 형광펜 방식 사용 없음

## 3. 강조 표현 방식

### 인라인 키워드 강조

- **방법**: 색상 교체 (bold serif 유지)
- **사용 컬러**: teal, orange-red, purple (슬라이드 맥락에 따라 단일 컬러 선택)
- 한 슬라이드에 강조색 1가지만 사용 — 혼용 없음

### 번호 목록 마커

- 원형 테두리 안에 숫자: **① ② ③** 스타일 (Unicode circled number 또는 SVG)
- 마커 컬러: 슬라이드 주 강조색과 동일
- 마커 크기: 본문보다 약간 작게 (0.85em 정도)

### 배지 / 태그

- 사용 없음 — 이 템플릿에는 badge 컴포넌트가 없음
- 대신 uppercase label + 타이틀 조합으로 계층 표현

### 섹션 포인터

- `→` 화살표: 섹션 목록에서 현재 위치 표시
- 폰트와 동일한 white/dark, bold 처리

### 인용 강조

- 배경색을 바꾼 전체 슬라이드로 인용 표현
- 장식용 `"` (따옴표) — 크게, 배경색보다 조금 더 어둡게 (10~15% opacity)
- 인용 본문: 대형 bold serif, 강조색

### 카드 / 패널

- 사용 없음 — flat 레이아웃 원칙
- 배경색이 다른 우측 패널로 시각 분리 (card border 없음)

### 세로 배열 박스 수 제한

- 콘텐츠 영역 내 세로로 쌓는 박스(카드/패널/팁)는 **최대 2개까지**
- 3개 이상은 마지막 요소가 잘리거나 여백이 무너지므로 금지
- 3개 이상의 내용이 필요하면 박스 내부에 목록(bullet-list)으로 통합하거나 다른 슬라이드로 분리

## 4. 코드 블록 스타일

> 이 Figma 템플릿은 코드 블록을 포함하지 않음  
> 아래는 전체 디자인 언어 기반으로 **코드 슬라이드 적용 규칙**을 도출한 것

### 구조 원칙

- 코드 블록은 본문 텍스트와 시각적으로 분리되어야 함
- 배경을 한 단계 어둡게 (bg-tertiary 사용)
- 테두리: 얇은 1px solid, 배경 대비 약 8~10% opacity

### 스크롤 규칙

- **세로 스크롤**: 코드가 블록 높이를 초과하는 경우 `overflow-y: auto` 허용  
  최소 높이(`min-height`)는 슬라이드 내 사용 가능한 공간 기준으로 충분히 확보
- **가로 스크롤**: 금지 — `white-space: pre-wrap` + `word-break: break-word` 유지  
  `overflow-x: hidden` 또는 `overflow-x: visible` 적용

### 라인 하이라이트

- 강조할 줄: 왼쪽에 2~3px 컬러 바 (primary accent color)
- 배경: accent-color 약 7~8% opacity overlay
- 행 전체를 가로로 채움 (margin 음수 트릭 활용)

### 인라인 코드

- 배경: accent-teal 10% opacity
- 텍스트: accent-teal 또는 bright code color
- 패딩: 2px 6px, border-radius: 3px

### 폰트

- 코드 전용 monospace: Monaco / Menlo / Consolas
- 슬라이드용 코드 폰트는 body보다 **1~2 size 작게** (가독성 확보)
- `pre` 내부: `white-space: pre-wrap` — 가로 스크롤 금지

## 5. 슬라이드 헤더 / 푸터 구조

### 헤더 (타이틀 슬라이드)

```
[LABEL — small caps, accent color, letter-spacing 0.2em]
[H1 메인 타이틀 — 2~3줄, bold serif, 대형]
[이름 bold  ·  날짜 regular  ·  부제 muted]
```

- 헤더 영역을 하단 구분선(1px)으로 body와 분리
- label과 타이틀 사이 gap: 매우 좁게 (~6~8px)
- 타이틀과 부제 사이 gap: 중간 (~16~20px)

### 헤더 (콘텐츠 슬라이드)

```
[LABEL — small caps, muted or accent]
[H1 타이틀 — bold serif, 여러 줄 가능]
```

- 레이블은 타이틀 위 바로 위에 위치, gap 8px 이내
- 섹션 구분선 하단에 1px border 추가

### 푸터

### 푸터

- 모든 슬라이드 하단 좌측에 고정
- 내용: 후츠릿 · {강의명} (강의명은 PPT 생성 시 입력받음)
- 강사명: 항상
- 스타일: --text-muted 컬러, Caption 크기, 좌측 정렬
- 슬라이드 번호, 각주 등 다른 요소 추가 없음

## 6. 전체 디자인 원칙 및 톤앤매너

### 핵심 원칙

1. **Less is more** — 한 슬라이드에 하나의 메시지
2. **Typography-first** — 이미지 없어도 텍스트만으로 완결된 슬라이드
3. **Color as personality** — 배경 컬러 자체가 섹션 아이덴티티
4. **No decoration** — 테두리, 그림자, 그라디언트 최소화

### 톤앤매너

- **Casual Yet Professional**: 딱딱하지 않지만 신뢰감 있는
- 세리프 폰트로 editorial / 잡지 느낌
- 여백이 많아 숨 쉬는 레이아웃
- 컬러는 과감하게 사용하되 슬라이드 전체를 한 색으로 — 복잡하지 않음
- 애니메이션/효과 없음 — 디자인 자체가 임팩트

### 반복 패턴

- 섹션 시작 = 단색 배경 풀슬라이드 (섹션 컬러로 전환)
- 콘텐츠 슬라이드 = 흰 배경 + label + 대형 타이틀 조합
- 임팩트 포인트 = 배경 컬러 전환 + 대형 serif 타이틀

## 7. 다크모드 컬러 시스템 제안

> 위 Figma 템플릿의 컬러 톤앤매너를 참고하여  
> 다크모드 기반, 강의 집중도 최적화 팔레트로 재설계

### 배경 계층

| 토큰         | hex       | 용도                                  |
| ------------ | --------- | ------------------------------------- |
| `--bg`       | `#0d1117` | 슬라이드 기본 배경 (GitHub dark 계열) |
| `--bg-card`  | `#161b22` | 카드, 패널 배경                       |
| `--bg-code`  | `#1e2430` | 코드 블록 배경                        |
| `--bg-inset` | `#252d3a` | 중첩된 요소, hover 상태               |

### 텍스트

| 토큰               | hex       | 용도                        |
| ------------------ | --------- | --------------------------- |
| `--text-primary`   | `#e6edf3` | 기본 본문 (약간 warm-white) |
| `--text-secondary` | `#8b949e` | 부제, 설명, 캡션            |
| `--text-muted`     | `#484f58` | 매우 흐린 요소, placeholder |

### 강조색 — Figma 원본 컬러에서 다크모드 최적화 도출

| 토큰              | hex       | 원본 대응                                        | 용도                                           |
| ----------------- | --------- | ------------------------------------------------ | ---------------------------------------------- |
| `--accent-teal`   | `#2DD4BF` | 원본 teal `#1A7A6E`, `#3BBCB8` → 명도 상향       | **주 강조** — 키워드, 숫자 마커, label, 진행바 |
| `--accent-orange` | `#FF6D3B` | 원본 orange-red `#F4400F` → 채도 유지, 명도 +10% | **경고/주의** — warn 카드 테두리, 주의 키워드  |
| `--accent-yellow` | `#F0B429` | 원본 gold `#F5B800` → 그대로                     | **수치/숫자** — 통계, 넘버, 부제 강조          |
| `--accent-purple` | `#A78BFA` | 원본 purple `#8930E8` → 명도 +30%                | **코드/정보** — 함수명, 특수 개념              |
| `--accent-green`  | `#4ADE80` | 원본 mint `#C5F5D8` 어둡게 → 채도 높임           | **성공/체크** — ✓ 마커, 완료 상태              |

| 토큰              | 값                       | 용도                     |
| ----------------- | ------------------------ | ------------------------ |
| `--border`        | `rgba(255,255,255,0.08)` | 기본 구분선, 카드 테두리 |
| `--border-accent` | `rgba(45,212,191,0.25)`  | 강조 카드 테두리         |

### 코드 블록 컬러

| 역할                 | hex                         |
| -------------------- | --------------------------- |

| 기본 코드 텍스트     | `#c9d1d9`                   |
| 키워드 (`kw`)        | `#f87171`                   |
| 함수명 (`fn`)        | `#c4b5fd`                   |
| 문자열 (`st`)        | `#93c5fd`                   |
| 숫자/변수 (`nm`)     | `#6ee7b7`                   |
| 주석 (`cm`)          | `#555f6e` (italic)          |
| 라인 하이라이트 배경 | `rgba(45,212,191,0.07)`     |
| 라인 하이라이트 바   | `#2DD4BF` (2px left border) |

### 배경 텍스처 (다크모드)

```css
background-image: radial-gradient(
  circle,
  rgba(255, 255, 255, 0.055) 1px,
  transparent 1px
);
background-size: 26px 26px;
```

### 컬러 사용 원칙

1. **슬라이드당 강조색 1가지** — Figma 원본과 동일한 원칙
2. `--accent-teal`이 primary — 80% 이상의 강조 요소에 사용
3. 나머지 accent는 역할(경고/성공/코드)이 명확할 때만 사용
4. 배경색 변경 슬라이드(섹션 전환 등)는 `--accent-teal`을 전체 배경으로 사용 가능
